# 登录方式配置（钉钉 / 飞书 / 企业微信）

平台的「管理 → 登录方式」里可以打开钉钉、飞书、企业微信登录（可以同时打开）。每一家都要先在它的开发者后台建一个**企业自建应用**，开好权限、配好地址，再把凭证填进平台。本页列出**每个功能要开的权限**：只开表里「必需」的就能用，「建议」的开了体验更好（比如按手机号对上已有用户）。

> 下面的 `<域名>` 是平台的访问地址（如 `one.example.com`），即「系统设置 → 基本信息 → 访问地址」去掉 `https://`。
> 开发者后台的菜单和权限名偶尔会改版，以后台显示为准；权限名找不到时，用表里的**权限代码**或**接口路径**在权限页搜索。

## 总览

| | 钉钉 | 飞书 | 企业微信 |
| --- | --- | --- | --- |
| 扫码 / 网页登录 | ✅ | ✅ | ✅ |
| 在客户端里打开时免登 | ✅ | ✅ | ✅ |
| 从通讯录同步部门和人员 | ✅ | ✅ | — |
| 第一次登录时按手机号 / 邮箱对上已有用户 | 开了手机号、邮箱权限才行 | 开了手机号、邮箱权限才行 | 新建的应用一般拿不到手机号（见下文） |

## 钉钉

### 1. 建应用、填凭证

1. [钉钉开发者后台](https://open-dev.dingtalk.com/) → 应用开发 → 企业内部应用 → 创建应用
2. 「凭证与基础信息」页的 **Client ID（原 AppKey）**、**Client Secret（原 AppSecret）**，以及开发者后台首页右上角的 **CorpId**，填到平台「管理 → 登录方式 → 钉钉应用」（同一页的「App ID」不用填）

### 2. 要开的权限

位置：应用 → 开发配置 → **权限管理**，逐个搜索、点「申请权限」（企业内部应用一般直接开通）。

| 用途 | 权限名称 | 权限代码 | 平台调用的接口 | |
| --- | --- | --- | --- | --- |
| 扫码登录：知道登录的是谁 | 通讯录个人信息读权限 | `Contact.User.Read` | `/v1.0/contact/users/me` | **必需** |
| 登录：查成员身份、姓名、部门、职位 | 成员信息读权限 | `qyapi_get_member` | `/topapi/user/getbyunionid`、`/topapi/v2/user/get` | **必需** |
| 第一次登录时按手机号对上已有用户 | 企业员工手机号信息 | — | `/topapi/v2/user/get` 返回的 `mobile` | 建议 |
| 按邮箱对上已有用户 | 邮箱等个人信息 | — | `/topapi/v2/user/get` 返回的 `email` | 建议 |
| 「用户与部门 → 从钉钉同步」：部门 | 通讯录部门信息读权限 | `qyapi_get_department_list` | `/topapi/v2/department/listsub` | 同步时必需 |
| 「用户与部门 → 从钉钉同步」：人员 | 通讯录部门成员读权限 | `qyapi_get_department_member` | `/topapi/v2/user/list` | 同步时必需 |

在钉钉客户端里打开平台时的免登（`/topapi/v2/user/getuserinfo`）不用单独开权限。

**通讯录权限范围**：权限管理页上方的「权限范围」选**全部员工**（或至少包含要登录、要同步的部门）。范围外的人登录会失败，同步也拿不到他们。

### 3. 要配的地址

| 位置 | 填什么 |
| --- | --- |
| 应用 → 开发配置 → 安全设置 → **重定向 URL（回调域名）** | `https://<域名>/auth/dingtalk/callback` |
| 应用 → 应用能力 → 添加「网页应用」→ **应用首页地址**、PC 端首页地址 | `https://<域名>/` |

### 4. 发布

应用 → 版本管理与发布 → 创建新版本 → **可见范围**选全员（或要用的部门）→ 发布。没发布、不在可见范围里的人，扫码后会被钉钉拦下。

### 5. 管理员

平台「钉钉应用 → 钉钉管理员（userid）」里填的人，第一次用钉钉登录时自动成为平台管理员。userid 在钉钉管理后台 → 通讯录 → 成员详情里。

## 飞书

### 1. 建应用、填凭证

1. [飞书开发者后台](https://open.feishu.cn/app) → 创建企业自建应用
2. 「凭证与基础信息」页的 **App ID**（`cli_` 开头）、**App Secret**，填到平台「管理 → 登录方式 → 飞书应用」

### 2. 要开的权限

位置：应用 → 开发配置 → **权限管理** → API 权限，搜索权限代码 → 开通。

| 用途 | 权限名称 | 权限代码 | 平台调用的接口 | |
| --- | --- | --- | --- | --- |
| 网页登录：拿到姓名、头像、open_id | （默认就有，不用开） | — | `/open-apis/authen/v1/user_info` | — |
| 第一次登录时按手机号对上已有用户 | 获取用户手机号 | `contact:user.phone:readonly` | 同上，返回 `mobile` | 建议 |
| 按邮箱对上已有用户 | 获取用户邮箱信息 | `contact:user.email:readonly` | 同上，返回 `email` | 建议 |
| 「用户与部门 → 从飞书同步」：部门 | 获取通讯录基本信息、获取部门基础信息 | `contact:contact.base:readonly`、`contact:department.base:readonly` | `/open-apis/contact/v3/departments/:id/children` | 同步时必需 |
| 「从飞书同步」：人员 | 获取用户基本信息 | `contact:user.base:readonly` | `/open-apis/contact/v3/users/find_by_department` | 同步时必需 |
| 同步时带上手机号、邮箱 | 获取用户手机号、获取用户邮箱信息 | `contact:user.phone:readonly`、`contact:user.email:readonly` | 同上 | 建议 |
| 同步时带上工号、职务、直属上级 | 获取用户工号、获取用户职务、获取用户直属上级等（以后台显示为准） | — | 同上，返回 `job_number`、`job_title`、`leader_user_id` | 可选 |

**通讯录权限范围**：应用 → 开发配置 → 权限管理 → **数据权限 → 通讯录权限范围**，选「全部成员」（或要同步的部门）。不配的话，同步时部门和人员都是空的。

### 3. 要配的能力和地址

| 位置 | 填什么 |
| --- | --- |
| 应用能力 → 添加 **网页应用** → 桌面端主页、移动端主页 | `https://<域名>/` |
| 开发配置 → 安全设置 → **重定向 URL** | `https://<域名>/auth/feishu/callback` |

### 4. 发布

应用发布 → 版本管理与发布 → 创建版本 → **可用范围**选全员（或要用的人）→ 申请发布（企业管理员审核通过后生效）。**权限改了要重新发一个版本才生效。**

没发布、或者不在可用范围里的人，授权时会被飞书拦下，提示「没有使用权限」。临时验证可以先把自己加为应用的测试人员。

### 5. 管理员

平台「飞书应用 → 飞书管理员」里填的人，第一次用飞书登录时自动成为平台管理员。**填 open_id（`ou_` 开头）或手机号**，不要填 union_id（`on_`）或 user_id——填错不会生效，也不会报错。open_id 可以在开发者后台「API 调试台」用当前应用查自己得到；同步过通讯录后，也能在「用户与部门」里把鼠标悬停在飞书标签上看到。

## 企业微信

企业微信的自建应用没有逐个勾选的 API 权限，要配的是**可见范围、可信 IP、可信域名**。

### 1. 建应用、填凭证

1. [企业微信管理后台](https://work.weixin.qq.com/wework_admin/) → 应用管理 → 自建 → 创建应用
2. 「我的企业 → 企业信息」页最下方的 **企业 ID（CorpID）**，应用详情页的 **AgentId**、**Secret**（点「查看」后在企业微信里接收），填到平台「管理 → 登录方式 → 企业微信应用」

### 2. 要配的

| 位置 | 填什么 | |
| --- | --- | --- |
| 应用详情 → **可见范围** | 要登录的人或部门 | **必需**：范围外的人登录会提示不是本企业成员 |
| 应用详情 → 开发者接口 → **企业可信 IP** | 平台机器访问外网时的公网出口 IP（隧道模式下是平台机器所在网络的出口 IP，不是云服务器的） | **必需**：2022 年以后新建的应用不配，调接口会被拒（错误码 60020） |
| 应用详情 → 开发者接口 → **网页授权及 JS-SDK → 可信域名** | `<域名>` | **必需**：要先通过验证文件校验（见下面），且域名的 ICP 备案主体要和企业一致（或有关联关系） |
| 应用详情 → 开发者接口 → **企业微信授权登录 → Web 网页 → 授权回调域** | `<域名>` | **必需**（扫码登录） |
| 应用详情 → 工作台应用主页 | `https://<域名>/` | 建议：在企业微信工作台里点开就是平台 |

**可信域名的验证文件**：企业微信会让你下载一个 `WW_verify_xxxxxx.txt`，要求 `https://<域名>/WW_verify_xxxxxx.txt` 能访问到它。不用动服务器：

1. 平台「管理 → 登录方式 → 企业微信应用」里，**可信域名验证文件名**填下载的文件名（如 `WW_verify_abc123.txt`），**验证文件内容**填用文本编辑器打开文件看到的那串字符，保存
2. 浏览器打开 `https://<域名>/WW_verify_abc123.txt`，能看到那串字符
3. 回企业微信点「验证」，通过后再保存可信域名

### 3. 手机号、邮箱

2022 年以后新建的自建应用，读成员详情（`/cgi-bin/user/get`）时**不再返回手机号、邮箱等敏感字段**，所以企业微信登录**一般没法按手机号对上已有用户**，平台按企业微信 userid 认人：

- 打开「首次登录自动建号」：每个人第一次登录时自动建号（姓名取不到时显示 userid，管理员可以在「用户与部门」里改）
- 或者在「企业微信管理员」里填 userid，让管理员先登录，再在「用户与部门」里管理其他人
- 企业微信不支持从通讯录同步部门和人员（钉钉、飞书支持）

## 配完怎么验证

1. 平台「管理 → 登录方式」打开对应开关，保存
2. 换一个浏览器（或无痕窗口）打开平台，用这种方式登录一次：进到工作台、姓名和部门正确，就是配好了
3. 在对应的手机客户端里打开平台首页：不用点登录直接进去，就是免登配好了
4. 要同步通讯录的：「管理 → 用户与部门 → 从钉钉 / 飞书同步」→ 先看预览，部门和人数对得上再同步

## 常见报错

| 现象 | 原因和处理 |
| --- | --- |
| 钉钉扫码后提示「没有权限」或接口报错 | 缺「通讯录个人信息读权限」或「成员信息读权限」；或者这个人不在通讯录权限范围、应用可见范围里 |
| 钉钉 / 飞书登录后手机号、邮箱是空的，没对上已有用户 | 没开手机号、邮箱权限（飞书改完权限要重新发布版本） |
| 飞书授权页提示「没有使用权限」 | 应用没发布版本，或者这个人不在可用范围里 |
| 飞书接口报错，信息里带 `99991672` 或 `scopes` | 缺权限：报错信息里列出的权限代码就是要开的那个，开通后重新发布版本 |
| 飞书同步的部门、人员是空的 | 「数据权限 → 通讯录权限范围」没选全部成员 |
| 企业微信登录报 `60020` / 「not allow to access from your ip」 | 没配「企业可信 IP」，或者配的不是平台机器的出口 IP |
| 企业微信授权页提示 redirect_uri 不合法 | 「可信域名」或「授权回调域」没填，或者和平台访问地址的域名不一致 |
| 企业微信可信域名「验证失败」 | 平台里填的验证文件名、内容和下载的不一致（打开 `https://<域名>/<文件名>` 看看）；或者域名的备案主体和企业不一致 |
| 所有方式的回调都报 redirect_uri 不匹配 | 平台的「访问地址」和开发者后台填的地址不一致（改过域名的要两边一起改） |
| 某个人能登录但不是管理员 | 管理员名单里填的 ID 类型不对（飞书要 open_id，钉钉和企业微信要 userid），或者他已经登录过——名单只在第一次登录时生效，之后在「用户与部门」里给他设管理员 |

另见：[统一认证（SSO）](/dev/sso)（应用怎么接平台的登录）、[用户主数据](/dev/users)。
