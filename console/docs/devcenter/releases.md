# 版本更新说明

以虎 One 的版本号是 `主版本.次版本.修订号`（语义化版本）。**0.x 是测试版（Beta）**：功能还在快速迭代，个别界面和接口可能调整，调整会写在这里和 [变更记录](/dev/changelog)。加功能升次版本号，只修问题升修订号；接口稳定后发 1.0。

当前版本在左侧栏底部、右上角头像菜单「关于」里可以看到；管理员在「管理 → 概览」里看升级。

## v0.4.0 · 2026-10-14

次版本：给老板的应用。没有不兼容的改动。

- **每日经营简报**：每天早上（默认工作日 8:00）把公司的关键数字、风险与变化、需要您决定的事汇总成一屏，推到您的钉钉 / 飞书 / 企业微信；点进去能接着问。首页「最新简报」卡片一键开通，或对 AI 助手说「每天早上 8 点给我发经营简报」
- **老板助理**：预置的 AI 助手，能读所有应用和知识库，先说结论、给数字和出处，不替老板改数据。默认只给管理员和部门负责人看见
- **管理层首页**：最新简报、关键指标、待我决策、风险与动态。管理员和部门负责人默认用它（系统设置 → AI 助手里可以关；自己改过首页的不受影响，可以在「编辑首页 → 套用：管理层」里换）
- **定时任务**：任何人都能设，比如「每周五 17:00 总结本周项目进展」。以本人身份运行，**只能查、不能改**，结果推到本人手机并存成对话（个人中心 → 定时任务）
- **应用的标准工具**：应用实现 `get_key_metrics` / `get_daily_summary` / `list_pending_decisions` 三个只读工具，就会出现在简报和管理层首页上，见 [让应用出现在老板的简报里](/dev/briefing)。[FDE 交付管理](https://github.com/guoylyy/yihu-fde) 0.3.0 已实现
- 助手设定新增「全部只读工具」；应用可见范围新增「部门负责人」
- 修复：应用发布了新的 AI 工具后，平台最多要等 5 分钟才能用上；现在发布完立即可用

升级：控制台「管理 → 概览」点「升级」，或在平台机器上执行 `./yh upgrade`；不能联网的机器把 `yihu-one-0.4.0.tar.gz` 和 `.sig` 一起拷过去执行 `./yh upgrade --package yihu-one-0.4.0.tar.gz`。升级时新增一张表（定时任务），并自动建好「老板助理」。推送简报要先在「管理 → 登录方式」配好钉钉 / 飞书 / 企业微信（钉钉还要填 AgentId）。

## v0.3.0 · 2026-10-14

次版本：代码应用的图标可以换得好看了，没有不兼容的改动。

- **开发者：用仓库里的图片做图标**。`yh-app.json` 的 `icon` 写图片文件名（如 `"icon": "icon.png"`，PNG / JPG / GIF / WebP / SVG，不超过 28KB，建议 128×128），发布时平台读这个文件做图标；换图标就是换文件再发布。见 [应用部署规范](/dev/deploy)
- **管理员：控制台里给代码应用换图标**。「管理 → 应用 → 设置」现在也能给从 Git 装的应用换图标（上传图片、内置图标、emoji、配色）；应用的创建者在「创作中心 → 上架信息」里换的也算。**换过以后，之后的发布不再用清单里的图标覆盖它**，想改回去点「恢复为代码里的图标」
- 以前在控制台给代码应用换的图标，下次发布会被清单覆盖；从这个版本起不会了（升级前已经被覆盖的，再换一次即可）

升级：控制台「管理 → 概览」点「升级」，或在平台机器上执行 `./yh upgrade`；不能联网的机器把 `yihu-one-0.3.0.tar.gz` 和 `.sig` 一起拷过去执行 `./yh upgrade --package yihu-one-0.3.0.tar.gz`。升级时会给应用表加两个字段（自动完成）。

## v0.2.0 · 2026-10-14

次版本：给应用新增两个开放接口，没有不兼容的改动。

- **应用信息**：新增 `GET /api/open/app`，返回应用所属的空间（和分享给的空间）、平台地址和外观（空间设了自己的 VI 用空间的，否则用平台的名称、LOGO、主题配色）。应用可以据此跟随平台外观，只服务自己的空间
- **给个人发消息**：新增 `POST /api/open/notify`，管理员安装或登记的应用可以经平台给指定的人发消息：按本人绑定的账号走钉钉工作通知、飞书卡片或企业微信应用消息，发不到的人会说明原因。员工发布的应用不能用
- **钉钉设置新增 AgentId**：「管理 → 登录方式 → 钉钉应用」里填上 AgentId，应用才能发钉钉工作通知；不填不影响登录
- [FDE 交付管理](https://github.com/guoylyy/yihu-fde) 0.2.0 起只作为以虎 One 的应用运行，用到以上两个接口，装它之前先把平台升到 0.2.0。详见 [应用信息与消息](/dev/notify)

升级：控制台「管理 → 概览」点「升级」，或在平台机器上执行 `./yh upgrade`；不能联网的机器把 `yihu-one-0.2.0.tar.gz` 和 `.sig` 一起拷过去执行 `./yh upgrade --package yihu-one-0.2.0.tar.gz`。

## v0.1.2 · 2026-10-13

修订版。

- **应用可以查平台给它用的模型**：新增 `GET /api/open/llm/models`（OpenAI `/models` 格式，`id` 就是调用时 `model` 填的值，第一个是默认模型），用应用自己的凭证调用；带 `X-User-Token` 时按这个人的角色过滤。不含密钥和上游地址。FDE 交付管理的「从以虎 One 同步模型」用的就是它，见 [接入大模型](/dev/llm)

升级：控制台「管理 → 概览」点「升级」，或在平台机器上执行 `./yh upgrade`；不能联网的机器把 `yihu-one-0.1.2.tar.gz` 和 `.sig` 一起拷过去执行 `./yh upgrade --package yihu-one-0.1.2.tar.gz`。

## v0.1.1 · 2026-10-13

修订版：修复几个在真实环境里碰到的问题，建议所有 0.1.0 平台升级。

- **AI 助手：应用工具多时不再报错**。平台工具加上应用的 AI 工具超过模型上限（OpenAI 兼容接口一般 128 个）时，所有能看到这些应用的人的助手都会请求失败；现在工具多的应用改为先查后调（`find_app_tools` / `call_app_tool`），写操作照样要确认。装 [FDE 交付管理](https://github.com/guoylyy/yihu-fde) 这类工具多的应用之前，先升级到 0.1.1
- **知识库**：向量化每批最多 10 条（部分向量模型一次只接这么多）、网络错误自动重试一次、出网优先 IPv4，修复在火山方舟等服务上知识库一直处理不完的问题
- **没开工具的 AI 助手**：改用不提「调用工具」的规则，修复 DeepSeek 等模型把工具调用标记当正文输出
- **登录方式配置说明**：开发中心新增 [登录方式配置](/dev/login-setup)，逐项列出钉钉、飞书、企业微信要开的权限和地址；企业微信可信域名的验证文件可以直接填在「登录方式 → 企业微信应用」里，不用动服务器
- **更新包签名**：从这个版本起更新包带签名。**升级到 0.1.1 以后，这台机器只接受以虎签名的更新包**（控制台点升级、`yh upgrade`、离线包都一样），从发布页下载的包都带签名，不用做什么

升级：控制台「管理 → 概览」点「升级」，或在平台机器上执行 `./yh upgrade`。不能联网的机器把 `yihu-one-0.1.1.tar.gz` 和 `.sig` 一起拷过去执行 `./yh upgrade --package yihu-one-0.1.1.tar.gz`。

## v0.1.0 · 2026-10-11

第一个公开测试版。

- **统一入口与登录**：账号密码、钉钉、飞书、企业微信登录；应用统一认证（平台 SDK）和标准 OIDC（GitLab、Grafana 等现成系统填几项配置即可接入）
- **应用**：外部应用登记、代码应用托管（推送自动发布，应用独立域名）、轻应用（对话生成）、AI 助手、Skill；应用市场与审核，可见范围按部门 / 人 / 角色
- **AI 助手**：每个人一位能调用各应用能力的助手，同一套工具通过 MCP 给 Claude Code 等 Agent 用；应用可调平台大模型接口，用量与配额可查
- **千人千面首页**：每人一份可编辑的首页，支持数据卡片
- **多空间**：一套平台给多家公司 / 客户用，空间之间互相看不到
- **资料中心**：公司模板、品牌 VI、设计组件，带版本和责任人，Agent 可按公司规范取用
- **视觉识别（VI）**：默认「以虎科技 VI」；管理员可以选预设、按公司 VI 改颜色、字体、圆角、阴影和 LOGO，**每个空间还可以有自己的 VI**（见下）
- **给新公司部署**：`install.sh --company …` 一条命令从零装一套（检查机器和网络、国内镜像、开机自启、备份、自检、生成交付单），云服务器 `cloud/install.sh` 可自动装好 Docker 和 Caddy；公司安装用更新包方式，升级由各公司自己决定。见 [部署手册](https://github.com/guoylyy/yihu-one/blob/main/docs/部署手册.md)
- **平台运维**：`yh` 命令行部署、平台一键升级 / 回滚、公网入口健康告警、发布通知

**升级注意**：0.1.0 起默认外观是「以虎科技 VI」。之前在「系统设置 → 外观与主题」里改过主色的平台，自动按「经典蓝 + 原来的主色」显示，样子不变；想换成新 VI，在那里选「以虎科技 VI」保存即可。
