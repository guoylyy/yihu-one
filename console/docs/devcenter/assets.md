# 资料中心

「资料」里放公司统一的素材：**模板**（PPT、文档）、**品牌 VI**（Logo、色板、字体、辅助图形）、**设计组件**、其他。人可以直接预览、下载；**Agent 可以按公司规范帮你做**——它从平台拿到结构化的品牌规范和文件，而不是去翻文档。

资料是素材，Skill 是做法：一份资料可以关联配套的 [Skill](/dev/skills)（比如「按公司规范做 PPT」），装上 Skill，Agent 就知道怎么用这份资料。问答类的需求（制度、流程）用知识库。

## 谁维护

- 管理员在「资料」里新建，并指定**责任人**；责任人和管理员能编辑、出新版本
- 每次更新是一个**版本**（一整套文件），版本记录里能看到谁在什么时候改了什么。没改的文件可以沿用，不用重新上传
- 资料属于一个空间，这个空间的人都能看到（平台开了多个空间时，别的空间看不到）

## 品牌规范

品牌 VI 除了文件，还可以填**结构化规范**，Agent 直接照着用：

| 字段 | 内容 |
| --- | --- |
| 颜色 | 名称、色值（`#RRGGBB`）、用在哪 |
| 字体 | 字体名、用在哪、没有这个字体时用什么 |
| 使用规则 | 一行一条，如「Logo 四周留白不小于 Logo 高度的 1/4」 |
| 文案口吻 | 如「专业、简洁，不用感叹号」 |

## 让 Agent 按公司规范做

先在「个人中心」把平台接到你的 Agent（见 [用 Agent 发布](/dev/agent-publish) 第 1 步），然后在「资料」页点「让 Agent 按公司规范做」，复制那段话给它，后面写上要做什么。

| MCP 工具 | 做什么 |
| --- | --- |
| `get_brand_guidelines` | 全部品牌规范（颜色、字体、规则、口吻 + Logo 等文件）和可用的模板，另带 `consoleTheme`：调用者看到的控制台配色（所在空间设了自己的 VI 就是空间的）。做 PPT、页面、海报前先调 |
| `list_assets` | 我能用的资料，可按类别（`TEMPLATE` / `BRAND` / `COMPONENT` / `OTHER`）筛；带我上次用的版本 `myVersion` |
| `get_asset` | 一份资料的规范和全部文件：小的文本文件（SVG、CSS、JSON、Markdown）直接给内容，其他给下载地址 |
| `check_asset_updates` | 传 `[{ id, version }]`，看手上的是不是最新版 |

文件的下载地址 **15 分钟内有效**，不需要登录，直接下载即可；过期了重新调 `get_asset`。

## 新版本提示

下载过、或让 Agent 取用过某份资料，平台会记下你用的版本。资料出了新版本，资料列表和详情页会提示「有新版本」，Agent 用 `check_asset_updates` 也能查到。

## 限制

单个文件最大 50MB，一个版本最多 30 个文件；不能上传可执行文件。文件和知识库的文档一样存在平台数据库里，备份会带上。
